# 🏢 GestImmo — Gestion locative

Logiciel de gestion locative pour immeubles et agences, sur téléphone et ordinateur. Installable comme une application, fonctionne hors ligne.

**👉 https://tchea1.github.io/gestimmo/** · **https://gestimmotabio.onrender.com**

## Fonctions
- Plusieurs immeubles, logements, registre des locataires, entrées / sorties, caution
- Loyers : payé, partiel, en retard, arriérés, **paiements d'avance** (« payé jusqu'à… »)
- **Moitié maintenant, reste promis** : accords de paiement avec date et alerte si non tenue
- **Reçus numériques automatiques** numérotés avec code de vérification (image, WhatsApp, impression)
- **Relances** WhatsApp / SMS (courtois, ferme, dernier rappel) avec historique
- **Contrat de bail** et **états des lieux** générés automatiquement
- **Relevé mensuel du propriétaire** avec commission de gestion
- Logo et coordonnées de l'agence sur tous les documents
- **Réparations avec preuves** : motif, matériel acheté, main d’œuvre, photos avant/après et reçus, fiche imprimable
- Dépenses avec justificatifs, tableau de bord, rapports annuels, exports Excel
- Code PIN, sauvegarde / import des données

Les données sont enregistrées dans le navigateur de l'appareil : exportez régulièrement une sauvegarde (Paramètres).
